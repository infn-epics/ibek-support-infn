# keysight-e36100

ibek support for the Keysight E36100B series DC power supplies (E36103B: 20 V / 2 A), from
[infn-epics/keysight-e36100](https://github.com/infn-epics/keysight-e36100): an asyn port driver over
SCPI on LAN port 5025, and two SNL state programs (`RampOn`, `SafeOff`).

One entity, `e36100.controller`, per supply:

| Parameter | Default | |
|---|---|---|
| `name` | | asyn port of the driver (the octet port is `<name>_IO`) |
| `P`, `R` | | PV prefix and device name: records are `$(P):$(R):<quantity>_RB` / `_SP` |
| `IP`, `TCPPORT` | 192.168.1.60, 5025 | the supply's LAN address and SCPI socket |
| `POLL`, `TIMEOUT` | 1.0, 2.0 | seconds between readback polls; reply timeout |
| `RETRY_DELAY` | 2.0 | seconds between command retries of the state programs |

Records: `Voltage`, `Current`, `OVP` (readback and setpoint), `VoltageSet`, `CurrentSet` (programmed
values), `Output` (bool), `Ident`, `Error` (lsi), `Connected`, and for each state program `:Start`,
`:Abort`, `:State`, `:Step`, `:Message`.

The module was generated by the ARGUS IOC engineer from
[a description of the device](https://github.com/infn-argus/argus-knowledge-hub/blob/main/docs/examples/keysight-e36100.yaml)
and run against its simulator; check it on a supply with the output unloaded before use.
